# Finance Tracker

Простое приложение по учету финансов, написанное на Node.js 22 и TypeScript без сторонних рантайм-библиотек. Приложение поднимает HTTP-сервер и предоставляет минимальный REST API для работы с доходами и расходами.

## Возможности

- Добавление новой операции (`income` или `expense`).
- Получение списка всех операций.
- Удаление операции по идентификатору.
- Получение агрегированной финансовой сводки (баланс, суммы по типам и категориям).
- Хранение данных в JSON-файле (`data/finance-db.json`).

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Соберите проект:
   ```bash
   npm run build
   ```
3. Запустите сервер:
   ```bash
   npm start
   ```

Сервер по умолчанию запускается на порту `3000`. Порт можно изменить с помощью переменной окружения `PORT`.

Для разработки удобно использовать ts-node (скрипт `npm run dev`).

## REST API

### `GET /transactions`
Возвращает список всех операций.

**Ответ**
```json
[
  {
    "id": "...",
    "type": "income",
    "amount": 15000,
    "category": "Зарплата",
    "description": "Аванс",
    "createdAt": "2024-09-18T10:00:00.000Z"
  }
]
```

### `POST /transactions`
Создает новую операцию.

**Тело запроса**
```json
{
  "type": "expense",
  "amount": 2500,
  "category": "Продукты",
  "description": "Закупка на неделю"
}
```

**Возможные ошибки**
- `400 Bad Request` — некорректные данные (тип, сумма, категория, дата).

**Пример запроса**
```bash
curl -X POST http://localhost:3000/transactions \
  -H "Content-Type: application/json" \
  -d '{
        "type": "income",
        "amount": 50000,
        "category": "Зарплата",
        "description": "Зарплата за сентябрь"
      }'
```

### `DELETE /transactions/:id`
Удаляет операцию. Если операция не найдена, вернется `404 Not Found`.

**Пример запроса**
```bash
curl -X DELETE http://localhost:3000/transactions/<transactionId>
```

### `GET /summary`
Возвращает агрегированную статистику.

**Ответ**
```json
{
  "incomeTotal": 20000,
  "expenseTotal": 5000,
  "balance": 15000,
  "byCategory": {
    "Зарплата": { "income": 20000, "expense": 0, "balance": 20000 },
    "Продукты": { "income": 0, "expense": 3000, "balance": -3000 }
  }
}
```

**Пример запроса**
```bash
curl http://localhost:3000/summary
```

## Развертывание на Vercel

Проект включает конфигурацию `vercel.json`, которая настраивает Node.js 20 serverless-функции и переписывает публичные маршруты `/transactions`, `/transactions/:id` и `/summary` на `/api`. Благодаря этому сервис можно деплоить на Vercel без дополнительной настройки — платформа больше не ожидает папку `public` после сборки. (На момент написания Vercel не поддерживает Node.js 22 в serverless-функциях, поэтому при деплое используется ближайшая доступная версия платформы.)

1. Выполните `npm install` и `npm run build` (или настройте автоматическую сборку в интерфейсе Vercel).
2. Задеплойте репозиторий. Запросы к `/transactions` и `/summary` будут проксироваться в `/api`, где используется та же бизнес-логика, что и при локальном запуске `npm start`.
3. Файл `api/[...route].ts` обрабатывает все вложенные маршруты в Vercel, что упрощает поддержку REST API.

## Примечания

- Приложение не требует внешней СУБД и может работать локально.
- Валидация данных осуществляется на сервере.
- JSON-файл создается автоматически при первом запуске.
