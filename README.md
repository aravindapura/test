# Accounting Ledger

Простое приложение для учета бухгалтерских операций на Node.js и TypeScript. Сервер предоставляет HTTP API для добавления операций и получения сводной информации о доходах и расходах.

## Возможности

- Добавление операций двух типов: `income` (доход) и `expense` (расход)
- Автоматическое сохранение данных в файл `data/transactions.json`
- Получение списка всех операций или фильтрация по типу
- Получение итоговой сводки с подсчетом доходов, расходов и баланса

## Требования

- Node.js 18+

## Установка и запуск

```bash
npm install
npm run build
npm start
```

Команда `npm start` запускает HTTP сервер на порту `3000` (порт можно изменить через переменную окружения `PORT`).

## Доступные эндпоинты

### GET /transactions

Возвращает список операций. Можно указать query-параметр `type` (`income` или `expense`) для фильтрации.

Пример ответа:

```json
{
  "data": [
    {
      "id": "1b8e...",
      "description": "Salary",
      "amount": 2500,
      "type": "income",
      "date": "2025-01-01T00:00:00.000Z",
      "category": "Payroll"
    }
  ]
}
```

### POST /transactions

Создает новую операцию. Тело запроса — JSON:

```json
{
  "description": "Office rent",
  "amount": 800,
  "type": "expense",
  "date": "2025-01-05",
  "category": "Office"
}
```

Ответ содержит созданную операцию с присвоенным `id`.

### GET /summary

Возвращает суммарную информацию:

```json
{
  "data": {
    "income": 2500,
    "expense": 800,
    "balance": 1700
  }
}
```

## Структура проекта

- `src/index.ts` — реализация HTTP-сервера и логики учета
- `data/` — каталог для хранения файла с операциями
- `dist/` — результирующие JavaScript файлы после компиляции TypeScript

## Разработка

Для обновления типов и логики достаточно отредактировать файлы в `src/` и заново выполнить `npm run build`.
