# Лотосные стопы (Lotus Feet)

Простое интерактивное Next.js-приложение на TypeScript, готовое к деплою на Vercel. Добавляйте изображения и описания
знаков лотосных стоп божеств, чтобы сделать карту интерактивной.

## Быстрый старт

```bash
npm install
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000).

## Структура данных

- Изображения размещайте в директории `public/images`. Файлы по умолчанию ожидаются с именами:
  - `public/images/shyama.png`
  - `public/images/radharani.png`
  - `public/images/gauranga.png`
- Описания знаков заполняйте в JSON-файлах `data/signs/*.json`.

Пример записи в JSON:

```json
{
  "signs": [
    {
      "id": "chakra",
      "title": "Чакра",
      "description": "Символ защиты и власти Господа.",
      "x": 120,
      "y": 200
    }
  ]
}
```

Координаты `x` и `y` указывайте в пикселях относительно исходного изображения — приложение автоматически масштабирует их
при изменении размера картинки.

## API

Данные о знаках доступны по маршруту `/api/signs/[deity]`, например `/api/signs/shyama`. Маршрут возвращает содержимое
соответствующего JSON-файла.

## Экспорт

Приложение настроено для статического экспорта (`next export`) и готово к деплою на Vercel без дополнительной настройки.
